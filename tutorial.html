Welcome. This is how I set up Claude.

Claude Code is Claude working on your own computer. This kit is the setup I use, and these slides walk you through it. They're follow-along only: you do everything by talking to Claude.

  • You need: a Mac or Windows, Claude Code and a paid Claude plan. The demo also needs Node. Windows also needs Git and Python, and goes without the dashboard and statusline.
  • Usage: install uses very little. The demo uses a lot: about 0.8M tokens in my test.

What you're building

A very simple Snake game for the web. You'll play it, invent your own strategies with Claude, run them thousands of times from fixed seeds, and chart which one solves it fastest.

  • Seed: like shuffling a deck in a known order. The same seed deals the same food every time, so runs can be compared.
  • Strategy: a small script that decides the snake's next move. The game ships with none. You make them.
  • CSV: a spreadsheet saved as plain text. Here, the results.

It takes an afternoon, and it's far more process than a game this small needs. That's on purpose: you're learning a flow for bigger work. Slides tagged optional can be skipped.

Your main chat only plans and hands out work. Plan at high effort, build at medium. The brief is examples/snake/BRIEF.md.

Invent a strategy

you and Claudeloop thiseffort: medium

The game has no strategies in it. This is the fun part: how would you play? Describe it in plain words. Claude writes it, you try it, and you go round again.

1. Describe it
Have a subagent (Opus, low) turn this into strategies/my-idea.js, with a decide(state) function: [how you'd play, in your own words]
2. Upload it
In the game, press Strategy file and pick strategies/my-idea.js.
3. Try it
Press Play and watch. When it dies, drag the step slider or click through the moves view to find where it went wrong.
4. Go again
At step [N] it [what went wrong]. Fix that in strategies/my-idea.js.
Upload it again and replay the same seed. Then try other seeds.
Worked if
